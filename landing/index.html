How Clay is different

Built from the ground up
for privacy-first teams.

Clay Code runs entirely on your hardware — no cloud calls, no data retention, no fine-print. And it gets smarter the longer you use it.

01

Runs on your hardware via Ollama

Clay Code uses ollama to run open-weight models — Llama 3, Mistral, Qwen, and more — directly on your CPU or GPU. No API key. No network required. Air-gapped deployments supported.

02

Persistent codebase memory

Clay builds a semantic index of your project that persists across sessions. It remembers the decisions you made, the patterns you prefer, and the context behind every file — so you never have to explain your architecture twice.

03

Improves the longer you use it

Hardware-adaptive routing selects the best local model for each task based on your machine's capabilities. As your codebase memory grows, Clay's suggestions become increasingly accurate and context-aware — all offline.

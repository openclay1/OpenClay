# Quickstart

## 1. Install and run

```bash
git clone https://github.com/openclay1/OpenClay.git
cd OpenClay
pip3 install -r requirements.txt
python3 app.py
```

OpenClay opens in your browser at `http://127.0.0.1:7861`.

## 2. Try something immediately

The first screen asks: *What are we working on?*

Click a starter action or type your own:

| Action | What happens |
|--------|-------------|
| **Organize this folder** | Scans the current directory, suggests renames and groupings |
| **Summarize these files** | Drop files first, then summarize — extracts key points |
| **Help me plan today** | Describe your goals, get a step-by-step plan |

## 3. Daily work

Open the **Daily Work** section for common tasks:

- **Summarize folder** — get a one-page overview of any directory
- **Clean downloads** — find and remove clutter from your downloads folder
- **Draft report** — produce a first draft from your recent files
- **Ingest docs** — add documents to your local wiki for future reference
- **Find duplicates** — scan for redundant files across directories
- **Expense notes** — create accounting summaries from transaction data

## 4. Drop files

Drag any file onto the drop zone. Documents get ingested into the wiki. Images get captioned. Everything stays local.

## 5. Optional: connect Twitter

If you want to post tweets, open the **Twitter (optional)** accordion and paste your four API keys from app `2040419672282087424anomalia939`. Hit **Save & Test Twitter**. This is not required for any other feature.

## 6. Check your progress

The **Local Success** section shows wiki pages, queued tasks, self-build runs, and generated artifacts. This updates every 60 seconds.

## 7. Clean up

Open **Storage** and hit **Clean Now** to rotate old logs and delete stale backups.

## That's it

OpenClay runs on your machine, answers to you, and gets better over time. No cloud account needed. No data leaves unless you add an API key and it needs to escalate — and even then, it asks first.
